# Solvely「从 Canvas 扩展到更多场景」静态板块

## 范围

只实现 Figma `262:12694` 的 Feature showcase：一个 1220 × 668 的浅灰圆角拼贴舞台及其下方文案。不修改前后模块，也不加入视频或新的交互。

## 视觉要求

- 舞台背景为 `#eef1f5`，圆角 32px；四张静态图维持 Figma 的 2×2 布局。
- 左上 YouTube、右上 Gmail、左下 Canvas 划选、右下 PDF 均使用 Figma 导出的原始图像；Canvas 图保持原稿的向上裁切。
- 标题为“从 Canvas 扩展到更多场景”，正文逐字保留 Figma 文案。
- 小屏等比缩放整组拼贴，圆角降为 20px、文案字体降为 16px。
