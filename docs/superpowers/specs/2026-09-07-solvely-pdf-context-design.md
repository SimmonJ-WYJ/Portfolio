# Solvely「让当前文档直接成为 AI 上下文」模块

## 范围

实现 Figma `262:12737` 的 PDF 展示模块；不改动 YouTube 总结或其他相邻板块。

## 视觉与内容

- 使用 1220 × 525 的 `#eef1f5`、32px 圆角舞台。
- 左侧 PDF 阅读器位于 58px / 30px，尺寸 882 × 466，保留原稿向上 15.11% 的内容裁切与 6px 圆角。
- 右侧插件侧栏位于 957px / 30px，尺寸 205 × 467，保留 0.49% 的顶部裁切和 6px 圆角。
- 两者之间使用原稿红色 SVG 连接箭头。
- 标题、正文逐字采用 Figma `262:12738`；移动端等比缩放，舞台圆角为 20px、文案为 16px。
