# Solvely「在用户当前网页位置直接提供帮助」模块

## 范围

实现 Figma `262:12743` 的网页划词动效模块；不改动 PDF 上下文或其他相邻板块。

## 视觉与内容

- 使用 1220 × 525 的 `#eef1f5`、32px 圆角舞台。
- 视频窗口位于舞台 206px / 54px，尺寸 808 × 499，保留 12px 圆角；窗口底部按原稿被舞台裁切。
- 使用用户提供的 `滑词.mp4` 作为真实内容；向上裁切 3.35% 以移除视频源顶部的黑边。
- 视频静音、循环，并在滚入视区后自动播放。
- 标题和正文逐字使用 Figma 文案；移动端保持比例缩放，舞台圆角为 20px、文案为 16px。
