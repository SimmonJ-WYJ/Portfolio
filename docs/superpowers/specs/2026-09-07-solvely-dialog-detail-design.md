# Solvely「AI 对话流细节优化」模块

## 范围

实现 Figma `262:12755` 的四卡并排静态模块；接在 Gmail 回复模块（`262:12730`）之后，不改动相邻板块。

## 视觉与内容

- 使用 1220 × 580 的 `#eef1f5`、32px 圆角舞台。注意本屏舞台高度为 580，与相邻模块的 525 不同。
- 四张 Solvely 侧边栏卡片并排，卡片本体为白色圆角面板，节点尺寸已包含约 17px 的投影外扩，故按节点坐标直接摆放即可保留投影。
- 卡片自左至右为 Crop（截图解题）、PDF（文档解题）、Summarize（网页总结）、Generate quiz（生成测验）；节点坐标 `47/35`、`330/35`、`614/34`、`898/35`，尺寸 273 × 512 与 274 × 512。Summarize 一张的 y 比其余少 1px，按原稿保留。
- 卡片间距恒定 10px，左右边距 47 / 48px，底部留白 33px；本屏无裁切关系。
- 标题和正文逐字使用 Figma 文案；排版沿用同族模块的 18px / 1.8 行高，标题 `#111827`、正文 `#57616e`，文案距舞台 24px。
- 移动端保持比例缩放，舞台圆角为 20px、文案为 16px。
