## 项目复盘 `262:12647`（1220 × 249）

- 复用页面既有的 `.sp-section` 排版：标题 32px / 1.3 / `#111827`，正文 16px / 1.65 / `#374151`，加粗 600 / `#111827`。原稿标题框高 43px 与 32 × 1.3 = 41.6 吻合。
- 正文为三段共五行（2 / 1 / 2）。段内行距 26px 与共享样式一致；段间另有约 26px 间距，而共享规则 `.sp-section-text p { margin: 0 }` 无段间距，故仅在本模块作用域内补 `p + p { margin-top: 26px }`，不影响既有的问题陈述与解决方案两节。
- 三处内联加粗逐字保留：`Onboarding 的目标并不是让用户完整了解产品`、`初创公司中设计流程是灵活的`、`核心任务建立最短价值路径`。
- 第二段使用弯引号 `“理想”`，第一、三段使用直角引号 `「」`，按原稿区分保留。

## 下载 CTA `264:12769`（1220 × 309）

- 整块为 `#eef1f5`、32px 圆角的浅色带，**不是**分隔线；原有脚手架里的 `border-top` 与 `margin-top/padding-top` 需按原稿改写。
- 内容水平居中，三者中心线均在 x = 610：吉祥物 GIF `(543,24)` 133 × 133、正文 `(439,169)` 342 × 52、按钮 `(517,233)` 186 × 52。
- 纵向节奏：上留白 24px → GIF 133 → 间距 12px → 正文 52（两行）→ 间距 12px → 按钮 52 → 下留白 24px。
- 按钮 186 × 52 = 文字 144 + 左右各 21px 内边距，高 = 13 + 26 + 13；`#007aff` 底、12px 圆角、白色 **带下划线** 文字 16px。原有脚手架的 `padding: 13px 32px` 与 `text-decoration: none` 均与原稿不符，需改。
- 复用仓库已有但此前未被使用的 `Solvely ip.gif`（1920 × 1920，84 帧）作为吉祥物，不新增资源。
