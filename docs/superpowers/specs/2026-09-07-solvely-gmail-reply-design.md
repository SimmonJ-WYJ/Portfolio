# Solvely「Gmail 邮件一键回复」模块

## 范围

实现 Figma `262:12730` 的 Gmail 邮件回复静态模块；接在划词模块（`262:12743`）之后，不改动相邻板块。

## 视觉与内容

- 使用 1220 × 525 的 `#eef1f5`、32px 圆角舞台，与相邻模块保持一致。
- Gmail 主界面位于舞台 169px / 42px，原稿尺寸 882 × 500；因舞台高度仅 525，底部 17px 被舞台裁切，可见区域为 882 × 483，故按 `top: 8%` / `height: 92%` 与舞台底边齐平。
- 底图使用设计方提供的 2646 × 1449 导出（882 × 483 的 3 倍图），两张 AI Reply 卡片已烘焙其中，无需再作为独立图层叠放。
- 连接线在 JSX 中以内联 SVG 绘制，不使用位图：沿用站内 `#FF9292` 箭头样式，viewBox `0 0 66 5.7735`，圆点在左、箭头在右，中心线对齐原稿 y=364。
- 标题和正文逐字使用 Figma 文案；排版沿用同族模块的 18px / 1.8 行高，标题 `#111827`、正文 `#57616e`。
- 移动端保持比例缩放，舞台圆角为 20px、文案为 16px。
